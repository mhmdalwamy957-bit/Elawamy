# تحديث فريق العوامي AI — المرحلة الأولى

## ما الذي يضيفه هذا التحديث؟

- مساعد خدمة عملاء أول يكتب الرد، ومراجع ثانٍ يراجعه قبل عرضه.
- ثمانية أدوار تطوير: المعمارية، الموقع، التطبيق، الخادم، Firebase، الأمان، الجودة، والنشر.
- صفحة أدمن على `/ai-team-admin.html` لإنشاء مهام التطوير ومراجعة التقارير والموافقة أو الرفض.
- كل قرار يُسجل في `aiTeamTasks` بواسطة الخادم فقط. قواعد Firestore تمنع القراءة والكتابة المباشرة من المتصفح.
- الموافقة لا تنفذ كودًا ولا تنشر الموقع ولا تغيّر بيانات العملاء أو الطلبات أو المدفوعات.

## هل هم عشرة نماذج مستقلة؟

لا. هذه عشرة أدوار متخصصة في سير عمل منسق، وليست عشرة نماذج منفصلة. Gemini يقوم بالتوليد الأساسي، ويمكن لمراجع OpenRouter مجاني مستقل مراجعة الناتج عند إعداد مفتاحه. إذا لم يتوفر، يستخدم النظام مراجعة ثانية عبر Gemini. لا يوجد ChatGPT API مدفوع في هذا التحديث.

## متطلبات التشغيل

1. احتفظ بنسخة احتياطية من الملفات الحالية قبل الاستبدال.
2. انسخ `server/server.js` إلى مجلد `server` في المشروع.
3. انسخ `public/ai.html` و`public/js/ai-assistant.js` إلى مساراتهما.
4. انسخ `public/ai-team-admin.html` و`public/js/ai-team-admin.js` إلى `public` و`public/js`.
5. حدّث `firestore.rules` في Firebase Console أو عبر أمر النشر المعتاد.
6. أعد نشر Backend على Vercel، ثم Hosting على Firebase لأن ملفات الواجهة تغيرت.

## متغيرات Vercel

- `GEMINI_API_KEY`: المفتاح الموجود لديك بالفعل.
- `GEMINI_MODEL`: يفضل ضبطه على `gemini-3.8-flash` إذا كان متاحًا ضمن الحصة المجانية لمشروعك.
- `OPENROUTER_API_KEY`: اختياري. عند تركه فارغًا، يستخدم النظام Gemini للمراجعة الثانية.
- `OPENROUTER_REVIEW_MODEL`: اختياري، والافتراضي `openrouter/free`. الكود يرفض أي قيمة لا تساوي `openrouter/free` أو ينتهي اسمها بـ`:free` لمنع اختيار نموذج مدفوع بالخطأ.

لا تضع أي مفتاح في ملفات `public` أو في المحادثة. أضف المفاتيح من إعدادات Environment Variables في Vercel فقط، ثم أعد نشر Backend.

## حدود المجانية والخصوصية

- Gemini Free tier له حدود استخدام تختلف باختلاف النموذج والمشروع. قد تستخدم Google محتوى الطلبات المجانية لتحسين منتجاتها؛ لذلك لا ترسل بيانات حساسة.
- OpenRouter المجاني يفرض حاليًا حدًا يصل إلى 50 طلبًا يوميًا و20 طلبًا في الدقيقة للنماذج المجانية ذات اللاحقة `:free`، وقد تتغير النماذج والحدود. المراجعة المجانية تضيف طلبًا ثانيًا لكل إجابة/مهمة عند توفر OpenRouter.
- يطلب الكود من OpenRouter حصر التوجيه في مزودين يعلنون عدم جمع البيانات وZero Data Retention (`data_collection: deny`, `zdr: true`). إذا لم يوجد مزود مجاني يفي بهذه السياسة، قد تتعذر المراجعة الخارجية ويعود النظام إلى Gemini.
- لا ترسل كلمات مرور أو رموز تحقق أو مفاتيح أو أرقام بطاقات أو تفاصيل عملاء/طلبات خاصة إلى المساعد.

## حدود المرحلة الأولى

- الفريق ينشئ خططًا وتقارير ومقترحات فقط.
- زر الموافقة يسجل `approved_for_manual_implementation`، ولا ينفذ أوامر ولا ينشئ Commit أو Pull Request ولا ينشر على Vercel/Firebase.
- التنفيذ الآلي يحتاج لاحقًا ربطًا مستقلًا وآمنًا بمستودع GitHub، وإنشاء فرع وPull Request، واختبارات ومراجعة بشرية قبل الدمج والنشر.

## فحوصات محلية

من مجلد المشروع نفذ:

```bash
node --check server/server.js
node --check public/js/ai-assistant.js
node --check public/js/ai-team-admin.js
npm run check
```

إذا فشلت فحوصات المشروع الحالية، لا تنشر التحديث قبل مراجعة الخطأ.
