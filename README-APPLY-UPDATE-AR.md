# تركيب تحديث منظومة الحلاقة 1.7.2

## تركيب التحديث على مشروع Termux الحالي

1. نزّل `elawamy-barber-upgrade-1.7.2.zip` إلى مجلد Downloads.
2. نفّذ:

```bash
cd ~/elawamy
unzip -o ~/storage/downloads/elawamy-barber-upgrade-1.7.2.zip -d ~/elawamy
npm run check && npm run test:barber
```

الحزمة لا تحتوي على `.env.local` أو مفاتيح خدمات أو مجلدات ربط `.vercel` و`.firebase`؛ فك الضغط فوق مشروعك لا يحذف هذه الملفات المحلية الموجودة بالفعل.

## إيه اللي اتضاف؟

- إجازات استثنائية للصالون بالكامل بالتاريخ `YYYY-MM-DD`، حتى 120 تاريخًا.
- التحقق من الإجازة في الخادم؛ يوم الإغلاق لا يعرض مواعيد، ويرفض الحجز المباشر أيضًا.
- إجازات الحلاق الفردية تستمر كما هي.
- اختبار تحقق إضافي لمنطق إجازة الصالون والحلاق وأيام الإغلاق الأسبوعية.
- رسالة أوضح عند تشغيل اختبار التكامل من غير محاكيات محلية.
- ملف `server/.env.example` توثيقي بلا أسرار.

## اختبار الحجز المتكامل محليًا

اختبار `npm run test:barber:local` يحتاج هذه الخدمات في جلسات Termux منفصلة:
- Firebase Auth Emulator على `127.0.0.1:9099`.
- Firestore Emulator على `127.0.0.1:8080`.
- API المحلي على `127.0.0.1:3000`، مع تعطيل XPay في جلسة التشغيل.

راجع `README-LOCAL-BARBER-TEST.md` لأوامر التشغيل. الاختبار لا ينشر الموقع ولا يستخدم بيانات الحجز الحية.

## النشر

لم يتم تنفيذ أي نشر من هذه الحزمة. بعد نجاح اختبار التكامل محليًا، انشر API على Vercel بمعاينة أولًا، اختبر الحجز والإجازات، ثم انشر الواجهة على Firebase. لا تنشر API للإنتاج بينما اختبار التكامل غير ناجح أو غير مُنفذ.
